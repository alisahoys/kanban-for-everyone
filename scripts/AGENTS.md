# Scripts

This folder contains start and stop scripts for local development.

## Included scripts

- `start.sh` and `stop.sh` for macOS/Linux
- `start.ps1` and `stop.ps1` for Windows PowerShell
- `start.bat` and `stop.bat` for traditional Windows command shells

## Purpose

These scripts launch the FastAPI backend locally and stop it by PID. The backend runs on port 8000 during the scaffolding phase.
